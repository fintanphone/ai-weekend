Pedagogical header: this script (step 3) refactors the previous "unrolled" agent turns into a single loop.

Core lesson stated explicitly: an agent is fundamentally a loop that repeatedly calls a model, lets it request tool use, runs those tools, and feeds results back—until done or stopped.

 
import json
import requests

import pi_tools

json: parse/serialize JSON payloads (for tool arguments and responses).

requests: HTTP client used to call the local LLM API endpoint.

pi_tools: custom module that defines:

  • Schemas for available tools (LIST_FILES, DELETE_FILE),
  • A dispatcher mapping tool names → actual Python functions,
  • The real filesystem/network operations on the Pi.

 
PAUSE = True
SERVER = "http://localhost:8080"
MAX_TURNS = 8               # the circuit breaker. See the note at the bottom.

PAUSE: when True, prompts the user to press Enter between important steps so you can read along (teaching mode).

SERVER: base URL of the local LLM inference server exposing an OpenAI-style /v1/chat/completions endpoint.

MAX_TURNS: safety limit on loop iterations—prevents runaway looping and expensive/unbounded tool use.

 
def pause(note):
    print()
    print("    " + "-" * 66)
    if PAUSE:
        input("    >>> " + note + "   (press Enter to continue) ")
    else:
        print("    >>> " + note)
    print("    " + "-" * 66)
    print()

Utility for readable, stepwise output:

  • If PAUSE is True, blocks at input() so the reader can inspect output before continuing.
  • If PAUSE is False, just prints the note (useful in automated or fast runs).
 
task = ("Log on to the Pi, go to my home directory, find all the .tmp files "
        "and delete the largest one if there is one.")

Human task description as a natural-language prompt. This file’s agent will attempt this exact instruction using available tools.

 
system_prompt = ("You are a careful assistant with access to a Raspberry Pi. "
                 "Use the tools rather than guessing. When the task is done, "
                 "say so in one sentence and stop calling tools.")

System message: sets behavior rules for the model:

  • Don’t guess—use provided tools.
  • Announce completion concisely and stop requesting tools when done.
 
messages = []
messages.append({"role": "system", "content": system_prompt})
messages.append({"role": "user", "content": task})

Builds the initial conversation history:

  • system: behavioral instructions.
  • user: the actual task to perform.
This history is sent in full each turn so the model always sees context. 

tools = []
tools.append(pi_tools.LIST_FILES_SCHEMA)
tools.append(pi_tools.DELETE_FILE_SCHEMA)

Define available tools as schemas the model understands (OpenAI-style function/tool definitions). Here:

  • LIST_FILES_SCHEMA: list directory contents.
  • DELETE_FILE_SCHEMA: delete a specific file.
 
tokens_sent_total = 0
tools_run_total = 0

Accumulators for transparency: track total prompt tokens sent across all turns and how many tool calls were executed.

 
print("TASK")
print("   " + task)
print()

pause("Here comes the loop. Put a breakpoint on the 'for turn' line.")

Echoes the task for visibility, then pauses so you can set a debugger breakpoint before entering the main agent loop.

 
final_answer = "(the loop ended without an answer)"

for turn in range(1, MAX_TURNS + 1):

    print("=" * 72)
    print("TURN", turn)
    print("=" * 72)

Main agent loop:

  • final_answer defaults to a placeholder; updated when the model provides a terminal response.
  • Loop runs from 1 to MAX_TURNS inclusive; each iteration is one "turn" of agent reasoning + possible tool use.
  • Prints a header for readability and debugging.
 
body = {
    "model": "local-model",
    "messages": messages,
    "tools": tools,
    "temperature": 0.0,
    "max_tokens": 800,
    "chat_template_kwargs": {"enable_thinking": False},
    "reasoning_budget": 0,
}

Constructs the HTTP request body for the LLM:

  • model: identifier for the local model to use.
  • messages: full conversation history (grows each turn).
  • tools: schemas of callable tools the model may request.
  • temperature 0.0: deterministic; minimize randomness for reliability in tool use.
  • max_tokens 800: cap on response length per turn.
  • enable_thinking / reasoning_budget: disable internal "thinking" steps to keep responses direct and cheaper.
 
http_reply = requests.post(SERVER + "/v1/chat/completions", json=body, timeout=180)
http_reply.raise_for_status()
data = http_reply.json()

Sends the request to the local LLM via an OpenAI-compatible chat completions endpoint:

  • timeout=180 allows up to 3 minutes for large/slow generations.
  • raise_for_status() fails fast on HTTP errors (5xx, etc.).
  • Parses JSON response into data.
 
tokens_sent_total = tokens_sent_total + data.get("usage", {}).get("prompt_tokens", 0)

Accumulates prompt (input) token usage from the model’s response metadata. Helps monitor cost and context growth; uses .get() to avoid breaking if fields are absent.

 
choice = data["choices"][0]
reply = choice["message"]
finish_reason = choice["finish_reason"]

Parses the assistant's response: takes first (and typically only) choice, extracts its message content and finish_reason to decide what to do next.

 
if reply.get("content"):
    print("   " + reply["content"].strip())

If the model produced natural-language text (e.g., explaining steps), prints it for visibility.

 
if finish_reason != "tool_calls":
    final_answer = reply.get("content") or "(no answer given)"
    print()
    print("   finish_reason is", repr(finish_reason), "- no tool wanted - the loop ends.")
    break

Key decision point:

  • If finish_reason is not "tool_calls", the model believes it is done (e.g., gave final answer) or stopped for another reason.
  • We capture its text as final_answer and break out of the loop—no more turns needed.
 
messages.append(reply)

Critical: append the model’s last turn (including its tool_calls) to messages so future calls see what it asked for. Without this, each request looks like a fresh start and coherence breaks.

 
for tool_call in reply["tool_calls"]:

    name = tool_call["function"]["name"]
    arguments = json.loads(tool_call["function"]["arguments"])

    print("   -> " + name + "(" + json.dumps(arguments) + ")")

If the model requested tools:

  • Iterate over each tool_call in its response.
  • Extract the function name and its JSON-encoded arguments, then parse them into a Python dict.
  • Log what’s about to be called for transparency.
 
function = pi_tools.DISPATCH.get(name)
if function is None:
    output = "ERROR: no such tool: " + name
else:
    output = function(**arguments)

Uses a simple dispatch map (name → actual callable). If unknown, returns an error string instead of crashing—keeps the agent alive and honest about what’s allowed.

 
tools_run_total = tools_run_total + 1

Increment total tool executions for final stats and observability.

 
for line in output.splitlines()[:6]:
    print("   <- " + line)

Prints up to the first 6 lines of tool output so you can see what happened without flooding the terminal.

 
messages.append({
    "role": "tool",
    "tool_call_id": tool_call["id"],
    "content": output,
})

Essential: feeds the result back into the conversation as a “tool” role message linked via tool_call_id. The model uses this to understand consequences of its actions and decide next steps.

 
print()
print("   messages:", len(messages), "items     tokens sent:", tokens_sent_total)
print()

Logs context size and cumulative token usage each turn so you can see how the conversation grows—useful for debugging and cost awareness.

else:
    print()
    print("   Hit the turn limit of", MAX_TURNS, "without finishing.")

Python’s for…else: if the loop completes without break, this runs—meaning we exceeded MAX_TURNS before the model signaled done. Acts as a safety notice.

 
print()
print("=" * 72)
print("ANSWER")
print("=" * 72)
print()
for line in final_answer.strip().splitlines():
    print("   " + line)
print()
print("   turns taken   :", turn)
print("   tools run     :", tools_run_total)
print("   tokens sent   :", tokens_sent_total)
print("   final messages:", len(messages))

Prints: the model’s final answer, plus a concise summary of:

  • How many turns were needed.
  • How many tool calls it made.
  • Total tokens sent and conversation length at the end.
 
pause("Scroll up. Count the lines in the loop. It is about fifteen.")

Pedagogical nudge: highlights that an entire agent loop—request, tool use, observe—is implemented in a very small amount of code.
